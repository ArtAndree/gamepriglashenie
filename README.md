# Детское приглашение-квест

Сайт для праздника 20–22 ноября 2026 года. Гостевой дом «Чайковский», Казань, ул. Дементьева, 51.

## Открыть
Откройте index.html. Сборка не нужна. Шрифт загружается из Google Fonts; без интернета используется запасной.

## GitHub Pages
Загрузите распакованные файлы index.html, README.md и .nojekyll в корень репозитория. В Settings → Pages выберите Deploy from a branch, main, / (root), Save. Публичный сайт будет доступен всем по ссылке.

## Игры
1. Платформер: 6 звёзд и флажок. На компьютере стрелки и пробел, на телефоне экранные кнопки. При падении звёзды сохраняются в текущей попытке.
2. Шарики: 12 попаданий за 30 секунд. Неограниченные повторы.
3. Память: 6 пар без ограничения времени.
4. Торт: 5 ингредиентов по рецепту.

После четырёх игр открывается приглашение PNG 1080×1440. Можно добавить имя и скачать или поделиться картинкой. Если браузер телефона открывает картинку вместо загрузки, сохраните её долгим нажатием.

Пройденные игры сохраняются в этом браузере через localStorage. Если хранилище недоступно, квест работает в текущем сеансе. Имя никуда не отправляется. Кнопка «Начать квест заново» очищает прогресс после подтверждения.

Уменьшение движения в настройках устройства отключает декоративные анимации. Платформер остаётся подвижной игрой.
